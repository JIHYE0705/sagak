# 첫 로컬 기록 흐름 검증 — 2026-11-12

## 구현 범위

Tauri + React + TypeScript + Vite, Rust `rusqlite`를 사용하는 macOS 앱을 초기화했다.
버터색 표지, 오늘의 좌우 속지, 날짜별 역할 제목·할 일·보조 칸·완료·메모 입력, SQLite 자동 저장과 오류·재시도, 정상 종료 시 저장 대기를 구현했다.
Enter로 다음 항목을 추가하며 Shift+Enter는 줄바꿈한다. IME 조합 중 Enter·keyCode 229는 추가 동작에서 제외한다.
다행체 원본 TTF·저작권 안내·라이선스를 앱에 포함했다. 외부 CDN 요청을 사용하지 않는다.

## 자동 검사

| 검사 | 결과 | 확인 범위 |
| --- | --- | --- |
| `npm ci` | 통과 | 잠금 파일로 설치 |
| `npm test` | 5개 통과 | 현지 날짜·초기 좌우 제목과 ID, IME Enter 분기, 빠른 입력 저장 순서, 저장 실패 후 최신 내용 재시도, 저장 완료 경계의 추가 입력 |
| `npm run build` | 통과 | TypeScript 검사·Vite 프로덕션 화면 빌드 |
| `cargo test --locked --manifest-path src-tauri/Cargo.toml` | 5개 통과 | SQLite 연결 종료·재열기, 긴 한글·줄바꿈·완료·보조 칸·날짜별 제목 보존, 다른 날짜 유지, 쓰기 거부 시 이전 기록 유지, 신규 스키마 거부, 손상된 기록 오류, 날짜·중복 ID 검증 |
| `cargo fmt --manifest-path src-tauri/Cargo.toml -- --check` | 통과 | Rust 형식 |
| `cargo clippy --locked --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings` | 통과 | Rust 전체 대상 정적 검사 |
| `npm run tauri build -- --debug --bundles app` | 통과 | Apple Silicon 개발용 `사각.app` 번들, 배포용 검수와 구분 |

환경: Apple Silicon Mac, Node 26.5.0, Rust 1.99.1, Xcode 명령줄 도구.
Rust 최소 설치를 진행하고 rustfmt·Clippy를 추가했다. 쉘의 PATH 파일은 변경하지 않았다.

빌드된 `.app`의 실행 파일도 시작했다. 실제 앱 데이터 영역에 `sagak.sqlite3`와 `pages` 테이블이 생성됐고 `user_version = 1`, `PRAGMA quick_check = ok`를 읽기 전용으로 확인했다. 이 확인에는 앱 창의 기록 입력·종료·재실행 조작을 포함하지 않는다.

## 브라우저 화면 검수

Playwright CLI로 개발용 브라우저 화면과 빌드된 화면을 확인했다. 브라우저 입력은 저장하지 않는다.

- 1240×800·960×640, 다행체·sans-serif 대체 글꼴, 14·24px의 8개 조합을 확인했다. 크기·글꼴 선택 UI는 미구현이므로 검사에서만 스타일을 강제 적용했다.
- 펼친 전체 외곽은 모든 조합에서 2:1이었다. 하단 표기가 종이와 뷰포트 안에 있었으며 200줄 한글 메모와 다수 할 일은 각 영역 안에서 스크롤됐다.
- 표지의 Enter 열기, 할 일 Enter 추가·Shift+Enter 줄바꿈, 완료 체크를 확인했다.
- 글꼴이 표시된 캡처와 대체 글꼴 적용 상태를 확인했다. 실제 로딩 지연·실패 타이밍과 macOS WebView 비교는 남아 있다.
- 로컬 검수 캡처는 `output/playwright/`에 저장했다(커밋 제외).

## 남은 검증과 한계

- 컴퓨터 제어 도구에서 권한이 없다고 응답해 실제 앱 창 입력·닫기·Cmd+Q·재실행을 자동 조작하지 못했다. DB 재열기 테스트와 `.app` 빌드 성공을 실제 앱의 종단 간 검증으로 간주하지 않는다.
- 실제 macOS 한글 IME, 스크린 리더, 중복 실행 포커스 이동, OS 재시작, 네트워크 차단 상태의 실제 앱 기록·조회는 미검증이다.
- 읽기 전용 쓰기 실패를 SQLite 테스트로 확인했다. 실제 디스크 부족·프로세스 강제 종료·전원 차단은 미검증이며 저장 완료 전 입력의 내구성을 보장하지 않는다.
- Intel·최소 macOS 11.0·서명·공증·DMG·설치·업데이트·DB 마이그레이션·JSON 백업·복원은 미검증 또는 미구현이다. 다음 스키마 변경에는 기존 DB 백업·마이그레이션 검증이 필요하다.
- 날짜 탐색·글꼴/크기/시작 화면/노트 이름 설정·삭제·항목 이동은 후속 작업이다. 관련 이슈를 일괄 완료 처리하지 않는다.

## 수동 인수 절차

1. `npm ci` 후 `npm run tauri dev`로 독립 앱 창을 연다. 또는 빌드한 `src-tauri/target/debug/bundle/macos/사각.app`을 연다.
2. 표지를 키보드로 열고 좌우 제목·가상 한글 할 일·보조 칸·완료·여러 줄 메모를 입력한다.
3. 저장 완료를 확인하고 닫기 버튼과 Cmd+Q를 각각 시험한다. 입력 직후 종료도 별도로 시험한다.
4. 재실행해 표지가 먼저 나오고, 노트를 열면 내용·순서·체크 상태·역할 제목이 그대로 나오는지 확인한다.
5. 최소 창과 긴 메모에서 하단 표기와 내용 끝에 접근되는지 확인한다. 한글 조합 확정 Enter로 의도치 않은 항목이 생기지 않는지 확인한다.

외부 백업이 아직 없으므로 이 빌드는 가상 기록 검수용으로 사용한다.
